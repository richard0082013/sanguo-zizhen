# 三国字阵

一款文字合成塔防游戏，灵感来自抖音游戏《赵云与阿斗》。

## 游戏介绍

《三国字阵》是一款 1v1 对战塔防游戏，玩家需要防守自己的阿斗（3条命），同时尝试击败对手。

### 核心玩法

1. **征兵系统**：消耗馒头招募随机字牌
   - 刀/枪/弓/骑：基础兵种，可自动攻击敌人
   - 武将字：收集武将名字的所有字可激活武将技能
   - 铲子：解锁新的格子

2. **合成系统**：相同类型、相同等级的字牌可以合成升级
   - 点击一个棋子选中，再点击另一个相同的棋子即可合成
   - 最高等级为 5 级

3. **武将系统**：当武将名字的所有字都放置在棋盘上时，武将技能激活
   - 例如：放置「赵」和「云」激活赵云的「七进七出」技能

4. **波次系统**：共 13 波敌人
   - 1-5 波：发育阶段
   - 第 6 波：第一个 BOSS
   - 7-12 波：混合敌人
   - 第 13 波：最终 BOSS

## 操作说明

1. 点击「征兵」按钮消耗馒头获得随机字牌
2. 点击棋盘上的空格放置字牌
3. 点击一个棋子选中（绿色边框），再点击另一个相同的棋子进行合成
4. 获得铲子后点击锁定的格子（黑色）解锁
5. 点击「开始波次」按钮开始下一波敌人

## 技术栈

- **游戏引擎**: Phaser 3
- **开发语言**: TypeScript
- **构建工具**: Vite
- **测试框架**: Vitest

## 本地运行

### 环境要求

- Node.js 18+
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

打开浏览器访问 `http://localhost:5173`

### 构建

```bash
npm run build
```

### 运行测试

```bash
npm run test
```

## 项目结构

```
src/
├── game/
│   ├── config/         # 配置文件
│   │   ├── generals.ts # 武将配置
│   │   ├── enemies.ts  # 敌人配置
│   │   ├── waves.ts    # 波次配置
│   │   ├── tiles.ts    # 字牌配置
│   │   └── gameConfig.ts # 游戏全局配置
│   ├── logic/          # 游戏逻辑（纯 TypeScript）
│   │   ├── BattleEngine.ts # 战斗引擎
│   │   └── types.ts    # 类型定义
│   ├── scenes/         # Phaser 场景
│   │   ├── BootScene.ts
│   │   └── GameScene.ts
│   ├── utils/          # 工具类
│   │   └── SeededRandom.ts # 可复现随机数
│   └── index.ts        # 游戏入口

└── style.css           # 样式
tests/
├── BattleEngine.test.ts # 战斗引擎测试
└── SeededRandom.test.ts # 随机数测试
```

## 设计说明

- **逻辑与渲染分离**: 战斗逻辑写成纯 TypeScript，便于移植到其他引擎
- **配置表驱动**: 武将、敌人、波次等数据通过配置表管理
- **种子随机数**: 使用固定种子的随机数生成器，保证游戏可复现
